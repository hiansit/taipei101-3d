# 台北101 (TAIPEI 101) 3D インタラクティブモデル

実在する超高層ビル「台北101（全高508.0m）」を、ブラウザ上で360度さまざまな角度からインタラクティブに鑑賞できるWeb 3Dモデルビューアです。  
外部の3Dモデルデータ（OBJ/GLTF等）を使わず、Three.jsによるプロシージャル（数理的）モデリングと動的Canvasテクスチャ生成のみで建築ディテールを再現しています。

---

## 🎮 主な機能・操作方法

- **マウス操作**:
  - **左ドラッグ**: 360° 自由回転（足元からの見上げや真上からの断面確認も可能）
  - **右ドラッグ**: カメラの平行移動
  - **ホイール**: ズームイン / ズームアウト
- **カメラアングル（視点プリセット）**:
  - 正面全景（写真再現）
  - 象山展望台（手前の鉄製手すりと緑の木々、隣接する台北南山広場ビルを含めた風景構図）
  - 見上げローアングル
  - 巨大古銭＆基壇部クローズアップ
  - 竹の節＆如意（双雲紋）ディテール
  - 頂上スパイア（尖塔）＆91F展望台
  - 87F〜92F 黄金ウィンド・ダンパー（TMD）透視
  - 真上からの平面断面（W字ステップコーナー）
- **環境・ライティング制御**:
  - 時間帯切り替え（快晴の昼景 / 夕景マジックアワー / 夜景ライトアップ）
  - 台北101 曜日別ライトアップ色（月〜日の7色LEDイルミネーション）
  - 太陽の向き（方位角）調整スライダー
- **構造・表示オプション**:
  - 外装ガラスの不透明度スライダー（内部透視）
  - 周辺の信義区街並み・山並みの表示 / 非表示
  - 建築部位アノテーション（解説ピン）表示 / 非表示
  - 自動ターンテーブル回転

## 🏛️ 建築再現のこだわり

1. **実寸スケール（1 unit = 1m / 全高 508.0m）**
   実寸比率に基づき、末広がりの基壇部から先端のスパイアまで狂いのないプロポーションで構築。
2. **W字ステップコーナー断面**
   東西南北の4つの主面と、四隅の2段セットバック＋斜めカットされた独特の輪郭をカスタムロフトジオメトリで定義。実物同様のシャープな垂直陰影ラインを再現。
3. **8つの「斗（竹の節）」と「如意（Ruyi）」**
   外側に約7度傾斜する逆テーパーモジュール（8階建て×8節）と、各節の上端に輝く白銀の双雲紋「如意」レリーフ（計32箇所）。
4. **24F〜27F「巨大古銭（方孔円銭）」**
   東西南北の4面にそびえる直径約19mの円盤（中央に正方形の枠）と、コーナーに巻き付く雲紋装飾。
5. **660トン 黄金ウィンド・ダンパー (Tuned Mass Damper)**
   第8節（87F〜92F）の内部に格納された、41層の鋼板ディスクからなる黄金球体と8本の吊り下げケーブル。強風時の制振振り子運動をシミュレーション。
6. **象山展望台からの台北風景構図**
   台北南山広場（高さ272m）、信義区の高層ビル群、背景の山並み、象山展望デッキの手すりまでを一体で配置。
